# FitTrack 💪

Modern ve kullanıcı dostu **fitness takip uygulaması**.

## ✨ Özellikler

- ✅ Kullanıcı giriş/kayıt sistemi
- ✅ Antrenman ekleme ve geçmişi görüntüleme
- ✅ Dashboard + Chart.js ile ilerleme grafikleri
- ✅ Beslenme Takibi
- ✅ Vücut Ölçümleri
- ✅ Admin Paneli
- ✅ Responsive tasarım (Tailwind CSS)
- ✅ Dark Mode Desteği

## 🚀 Nasıl Çalıştırılır?

1. Projeyi indir veya clone et
2. `index.html` dosyasını tarayıcıda aç
3. Test hesapları:

   **Normal Kullanıcı:**  
   `test@fittrack.com` / `123456`

   **Admin:**  
   `admin@fittrack.com` / `admin123`

## 🛠 Kullanılan Teknolojiler

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Chart.js
- localStorage
